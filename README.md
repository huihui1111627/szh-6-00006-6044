# 山区森林火灾空地协同推演平台

纯前端交互式推演系统，无需构建，直接用浏览器打开 `index.html` 即可
（或运行 `python3 -m http.server 8080` 后访问 http://localhost:8080）。

## 功能

- **态势推演**：网格化山区地形（高程/植被/湿度/水源/道路网），火势按风向、
  坡度、湿度蔓延，遇到湖泊、道路、已建成隔离带会自然绕行。
- **指挥交互**：
  - 拖设隔离带：在地图上按住拖动划线，自动指派最近地面队伍前往开设；
  - 调整进入方向：在"救援力量"面板为每支队伍选择从北/南/东/西侧进入火场；
  - 道路封控：点击道路封闭/解封；点击队伍后再点击地图可下达机动/扑打指令，
    直升机则为指定吊桶灭火点。
- **突发事件**：风向突变、道路塌方失效、通信中断（可手动触发，也有剧本事件）。
  事件发生后系统自动评估已下达行动的可行性，在"告警处置"面板列出
  **需要撤离的队伍** 和 **需要重新确认的任务**，可一键撤离/重新规划/确认继续。
- **通信中断与恢复**：中断期间指令暂存待下达，现场力量按最后指令继续行动，
  地图同时显示"最后已知位置"幽灵标记；恢复后弹出核对窗口，列出每支力量
  原计划与现场实际的差异，可选择"以现场为准并下达暂存指令"或"仅同步状态"。
- **策略并行回放**：三套预案（地面分段阻截 / 空地协同封控 / 重点目标保卫）
  在相同起火条件、相同突发事件下并行推演，支持播放与拖动时间轴，
  实时对比过火面积、目标受损、撤离告警、重新确认次数。
