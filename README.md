# 山区森林火灾 · 空地协同推演

纯前端交互原型（无构建、无外部依赖），双击 `index.html` 或用任意静态服务器打开即可使用。
想定固定起火点（同一种子，结果可复现），围绕**火线扩散、风向/地形、道路通行、隔离带、空地力量任务、多策略并行回放、通信中断与恢复对账**展开。

## 运行

```bash
# 方式一：直接双击 index.html
# 方式二：静态服务器
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

推荐窗口宽度 ≥ 1400。空格 = 播放/暂停，Esc = 取消当前编辑模式/关闭弹窗。

## 操作指引

- **指定进入方向**：点选队伍 → 在地图上点击道路节点，队伍沿道路网最短路径机动；道路封闭或被火切断时指令被拒绝。
- **拖画隔离带**：顶栏「✂ 隔离带」→ 图上按住拖画（不得穿水/明火），规划后在力量面板/隔离带上派工程队前往开设。
- **关闭危险道路**：「🚧 封路」→ 点击道路边；在途队伍任务立即重新评估，若剩余路线被切则任务标红“需重新确认”。
- **空中力量**：选中直升机后点击明火点即派吊桶洒水（自动往返最近水源），也可派往目标巡护。
- **风向调整**：「🌬 风向」弹窗拖转盘或用方位预设；风向突变后所有在执行任务自动复核。
- **多策略并行回放**：「⧉ 分叉策略」在当前时刻复制出方案 B/C/D（相同起火与气象种子），「▦ 对比」并列同步回放，右侧“策略对比”页给出过火面积、目标损失、撤离告警、任务重确认、隔离带/洒水等指标对比。
- **通信中断演练**：「📵 中断通信」后真实态势继续推演，期间下达的指令进入待确认队列；「恢复通信并对账」弹出四栏对账：
  - 需要撤离的队伍（距明火小于临界半径 / 任务已不可执行）
  - 需要重新确认的任务（道路被切、航线穿火、现场位置/进度偏离计划）
  - 中断期间待确认指令（按恢复后实况逐条预检，可下达或废弃）
  - 现场新发现（队伍位置偏差、可能的飞火新火点）

## 页面要素

- 顶部：模拟时钟（`T+时:分`）、播放/单步、1–30× 速度、全局气象与封路/隔离带工具、分叉/对比、通信中断、重置。
- 地图：值噪声地形（高程+可燃物，含等高线）、河道与湖泊、道路网（节点+边，封闭显红斜纹）、明火/过火/湿化、地面队（圆）与直升机（菱形）、保护目标（风险色六边标+ETA）、风玫瑰。
- 右侧四页：救援力量（任务状态、进度、告警、重新确认/撤离/取消）、保护目标（四级风险与防护力量）、策略对比（指标表）、指令日志（气象/指令/系统/失败）。
- 顶部红色横幅：撤离级危险自动暂停推演并点名队伍；风变给出黄色警告。

## 模型摘要（`js/sim.js`）

- 网格 96×70，1 步 = 1 模拟分钟；火势按格点元胞自动机扩散，概率受可燃物、坡度、风速在传播方向的投影、道路裸地、洒水湿化与隔离带阻断影响；每格有燃料相关燃烧寿命，扑打/洒水累计“抑制量”缩短寿命。
- 道路为无向图（路口/村寺营地/停机坪/取水点），地面队只能沿图机动，Dijkstra 最短路且回避封闭边；边在明火格 ≥3 时视为被火切断。
- 任务（机动 / 开隔离带 / 守点防护 / 直升机吊桶往返 / 撤离）周期复核：地面检查剩余路线，空中检查航段是否穿越明火；失效任务不会继续移动，必须“重新确认”（自动按当前态势重新规划）或撤离/取消。
- 目标风险按最近明火距离、风向是否吹向目标、地表推进速度估算到达时间（ETA），分安全/关注/较高/危急四级，有队伍守点降一级；目标半径被火侵入即计损失。
- 通信恢复时对现场施加确定性“偏差”（队伍位置漂移、可选飞火点），再与中断前快照比对生成对账清单。

## 文件结构

- `index.html`：布局（顶栏、告警横幅、地图栈、右侧面板、风向/对账弹窗）
- `css/style.css`：暗色指挥台样式
- `js/util.js`：确定性随机（可存状态）、值噪声、栅格化/几何/时间工具
- `js/scenario.js`：想定生成（地形、水系、道路图、力量、目标、初始风与 90 分钟风变事件）
- `js/sim.js`：推演引擎（火势、寻路、任务、失效复核、指标、通信对账、克隆）
- `js/render.js`：离屏地形缓存与逐帧态势绘制、命中检测
- `js/ui.js`：视图管理、地图交互、侧边面板、弹窗、通信流程
- `js/main.js`：按钮接线与主时钟循环
